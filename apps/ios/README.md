# Tailored Agents for iPhone

A private UIKit/WebKit companion with Mail and Dashboard tabs. The first version loads the existing Cloudflare mail site and Render dashboard. It has no separate backend, database, embedded credentials, analytics SDK, or paid dependencies. The iOS app requires iOS 17 or later and an internet connection.

Each tab retains its own web view when switching. Both use WebKit's persistent website data store; sign in separately to Mail and Dashboard with the existing account credentials. Session expiration, password resets, and authorization remain controlled by the servers. Browser sessions in Safari are separate from the app's sessions.

## Build and install

Install full Xcode and complete its first-launch setup. The scripts default to `/Applications/Xcode.app/Contents/Developer`; override `DEVELOPER_DIR` for another installation. They do not change the Mac's global command-line-tools selection. No third-party Swift packages or project generators are required.

From the repository root:

```sh
bash apps/ios/scripts/test.sh
bash apps/ios/scripts/build-ipa.sh
```

The build produces `apps/ios/build/TailoredAgents.ipa`. This is an unsigned device build prepared for Sideloadly, which signs it with the user's own Apple account. It cannot be installed directly until signed. The bundle identifier is `com.tailoredagents.workspace`; keep the same identifier and signing account when updating to preserve app storage.

1. Open [Sideloadly](https://sideloadly.io/) on the Mac and connect an unlocked iPhone by USB.
2. Accept the trust prompts in Finder and on the iPhone.
3. Select the phone and drag `TailoredAgents.ipa` into Sideloadly.
4. Enter the Apple account directly into Sideloadly and complete its sign-in prompts. Do not store credentials in this repository.
5. Enable Sideloadly's automatic refresh option and install the app.
6. Follow iOS prompts for Developer Mode and developer trust under Settings → General → VPN & Device Management.
7. For Wi-Fi refresh, enable **Show this iPhone when on Wi-Fi** in Finder. Sideloadly's refresh helper and the phone must be able to connect over Wi-Fi or USB before the seven-day free-account signing period expires. If it expires, refresh from the Mac before opening the app again. See [Sideloadly's FAQ](https://sideloadly.io/faq.html).

Open `TailoredAgents.xcodeproj` for normal Xcode development. Its checked-in project and shared scheme are generated by `python3 apps/ios/scripts/create-project.py`; update the generator when adding sources or build settings, then regenerate. AppIcon.png is rasterized from the repository's existing `app/icon.svg`.

## Behavior and boundaries

- Mail opens `https://mail.tailoredagents.com/inbox`; Dashboard opens `https://www.tailoredagents.com/dashboard`.
- First-party HTTPS links stay in the appropriate tab. External websites, phone links, and email links open through iOS. New-window links work without creating untracked web views. Unknown URL schemes, credential-bearing URLs, and insecure versions of the app origins are blocked.
- The web views use native safe areas and the keyboard layout guide. A Done button dismisses the keyboard so the bottom tabs are reachable while composing. The Back button and swipe navigation follow web history. The page menu provides Reload and Open in Safari. Reloading a compose/thread page asks the user to check the draft's Saved status first.
- Attachment downloads and CSV/PDF exports use WebKit's authenticated download flow and the iOS share sheet, including Save to Files. Download filenames are bounded and reduced to a single safe path component. Temporary files are protected, excluded from backup, and removed after sharing or on the next launch. Cross-origin download redirects are rejected; current attachment endpoints stream through their original host.
- Existing web file inputs provide Photos/Files uploads. Camera and microphone usage descriptions cover taking a photo or recording a video when explicitly chosen from the attachment picker.
- Google Search Console account linking is completed in Safari, then Dashboard can be reloaded in the app. This avoids attempting Google's sign-in inside an embedded browser and keeps the OAuth cookies together.
- The app switcher obscures the workspace when the app becomes inactive. TLS verification and server-side access controls retain their platform defaults.
- Push notifications, background mailbox fetching, offline mail, Face ID app locking, and a unified single sign-in are not included in this initial version. Changing the installation method does not add those capabilities.

Website changes appear through the existing deployments. Native changes require rebuilding and reinstalling the IPA. Pushing this repository does not deploy the Cloudflare mail service or install the iOS app.

`scripts/test.sh` compiles the shared navigation and filename policy for macOS and checks trusted origins, lookalikes, credentials in URLs, URL schemes, blob origins, sandboxed message frames, download responses, and filename traversal/length limits.

The UI smoke test loads the two live **sign-in pages**, enters a synthetic `.invalid` email address without submitting it, and checks tab switching, preserved input, keyboard access to tabs, and the page menu. It sends no messages and changes no production account data. Run it against an already installed iPhone simulator:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project apps/ios/TailoredAgents.xcodeproj -scheme TailoredAgents \
  -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath apps/ios/build/DerivedData \
  -parallel-testing-enabled NO CODE_SIGNING_ALLOWED=NO test
```
